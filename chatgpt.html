FTW for ChatGPT

Get help installing FTW, understand your home's energy flow and plans, and investigate problems with supported meters, solar, batteries and EV chargers.

Public directory release in preparation. Sourceful Labs AB develops this integration. It is not yet listed as an approved public plugin. Existing development connections remain separate.

No FTW box yet?

The Setup Guide helps you choose a host, follow the current install guide, connect supported equipment and check fresh readings. You do not need a connected home to ask for setup help. You run the install on your own host; ChatGPT cannot log in to your Pi or router for you.

Start with Install and update FTW. Check your model and tested functions in the device catalog. A catalog entry alone does not prove control on your equipment.

Understand a connected home

With your approval, ChatGPT can read current power, battery and car state, past power readings, the planner's proposals, equipment health, and redacted logs and settings. Old and missing readings remain distinct from fresh measurements. Plans and estimated savings do not prove what the equipment did or what you saved.

The public connection uses a fixed set of named tools. It does not offer arbitrary API access, backup exports or remote setup writes. When a question needs data it cannot read, it explains the gap and guides you through a local check.

Approve access in FTW

  1. Run a current FTW beta, enable FTW Cloud on the box and read the Cloud information before accepting it.
  2. Start the FTW connection in your ChatGPT development installation. The FTW authorization page shows a code and a link for the owner.
  3. Approve the request in your FTW app or the box's own Access page. Choose the rights and how long access lasts. Keep passwords, keys and approval codes out of chat.
  4. Ask which home ChatGPT can reach and what you granted. You can end access in FTW at any time.

Reading is separate from control. A short charging action needs your request and a matching grant. A request for a lasting goal change waits for the owner's approval. Core checks every command and keeps control on the box.

Your data

FTW Cloud can read this assistant connection while it passes requests and answers between ChatGPT and your box. OpenAI receives the data you authorize the connection to return. See Privacy: assistants and the plugin terms.

Get help

  • Email support@sourceful.energy.
  • Report a problem in FTW issues. Include the running Core version, the question, the error and its time. Remove home identifiers and secrets.
  • Read the support policy. Community help is best effort.
