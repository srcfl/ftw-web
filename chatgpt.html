FTW for ChatGPT

Get help installing FTW, understand your home's energy flow and plans, and investigate problems with supported meters, solar, batteries and EV chargers.

Not in ChatGPT's plugin directory yet. Sourceful Labs AB develops this integration, and it waits for OpenAI's review. Until it is listed, you can add it to ChatGPT yourself, as the steps below show.

No FTW box yet?

Install FTW first. Get started shows what you need and the two ways to install it yourself: the Home Assistant button, or one line for a 64-bit Linux computer. Give ChatGPT that page and it can help you step by step. You run the install on your own computer; ChatGPT cannot log in to your Pi or router for you.

Check your model and tested functions in the device catalog. A catalog entry alone does not prove control on your equipment.

Understand a connected home

With your approval, ChatGPT can read current power, battery and car state, past power readings, the planner's proposals, equipment health, and redacted logs and settings. Old and missing readings remain distinct from fresh measurements. Plans and estimated savings do not prove what the equipment did or what you saved.

The public connection uses a fixed set of named tools. It offers no arbitrary API access and no backup exports. When a question needs data it cannot read, it explains the gap and guides you through a local check.

Connect ChatGPT

  1. Run a current FTW beta, enable FTW Cloud on the box and read the Cloud information before accepting it. Finish the setup guide, then connect the assistant under Settings → Access. On a new box from the next beta, you can also choose Set up with ChatGPT or Claude instead on the first page.
  2. In ChatGPT on the web, open Plugins, choose +, then Add custom MCP server. Give it a name and paste this address:
    https://cloud.ftw.energy/mcp?profile=public
    In a Business workspace, an admin adds it. On a Pro plan, ChatGPT can read your home but cannot control it or set it up.
  3. ChatGPT opens the FTW authorization page. It shows a code and a link for the owner. It also says that FTW Cloud has not checked this assistant: check that it names ChatGPT.
  4. Approve the request in your FTW app or the box's own Access page. Choose the rights and how long access lasts. Keep passwords, keys and approval codes out of chat.
  5. Ask which home ChatGPT can reach and what you granted. You can end access in FTW at any time.

Reading, control and setup are separate. A short charging action needs your request and a matching grant. A request for a lasting goal change waits for the owner's approval. The setup tools can look for devices on your home network, test a device with control blocked, change the box's settings and restart it. They need a separate setup grant, which the owner approves on the box. With that grant, ChatGPT can save settings after you review and confirm the exact draft, and restart the box after you confirm the short break. Core checks every command and keeps control on the box.

Your data

FTW Cloud can read this assistant connection while it passes requests and answers between ChatGPT and your box. OpenAI receives the data you authorize the connection to return. See Privacy: assistants and the plugin terms.
