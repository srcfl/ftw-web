Get started with FTW

FTW runs on a computer in your home. It plans your battery, car and solar around prices and the weather, then runs them. Here is what you need, and four ways to start.

What you need

  • A computer at home that stays on. Home Assistant, or any 64-bit Linux computer with systemd: a Raspberry Pi 3 or newer, a mini PC or an old laptop.
  • Equipment FTW supports, on your home network: an inverter, battery, EV charger or meter. Search yours by brand in the device catalog. 6 of 91 drivers are confirmed on real hardware so far.

FTW is in public beta. There is no stable release yet, and it changes often. Tell us in the FTW Discord what works and what breaks.

Four ways to start

1 Home Assistant

  1. Choose the button. It adds the FTW repository to your Home Assistant.
    Add to Home Assistant ↗
  2. Install FTW (beta).
  3. Choose Start.
  4. Choose Open Web UI. FTW opens inside Home Assistant. To keep it in the sidebar, turn on Show in sidebar.

Needs Home Assistant OS. Step by step

2 A Linux computer

Any 64-bit Linux computer with systemd: a Raspberry Pi 3 or newer with Raspberry Pi OS Lite (64-bit), a mini PC or an old laptop.

  1. Run this line on that computer:
    curl -fsSL https://ftw.energy/install.sh | bash -s -- --fresh-host
  2. Open the address it prints, such as http://192.168.1.23:8080/setup, in a browser on the same network.

It installs the newest release on a computer with no FTW yet. Step by step. Already running FTW? Switch or update.

3 A ready box

A small computer set up for FTW, ready to plug in. It is not on sale yet. Join the waitlist and we'll email you when orders open.

4 Start from an AI assistant

Claude or ChatGPT can set up your home with you, once FTW runs on your computer.

  1. Install FTW first, with way 1 or 2.
  2. On the box's first page, choose Set up with ChatGPT or Claude instead. Already set up? Connect later under Settings → Access.
  3. Add FTW to your assistant with this address:
    https://cloud.ftw.energy/mcp?profile=public
    • Claude: in Claude on the web, desktop or phone, open Settings → Connectors. Choose Add custom connector, paste the address and leave the client ID empty.
    • ChatGPT: FTW is not in ChatGPT's plugin directory yet; it waits for OpenAI's review. Until then, add the address as a custom MCP server on ChatGPT's Plugins page. Some workspaces need developer mode turned on first. More about FTW for ChatGPT
  4. The assistant opens an FTW Cloud page with a code. Type the code on the box under Settings → Access, or approve it in the FTW app.
  5. Ask the assistant to set up your home. It reads only what you allow. Control and setup are separate grants, and the box checks every step.

Need help with the install itself? Give any assistant this page, https://ftw.energy/start, and ask it to walk you through. Grok, Cursor, Claude Code and Codex connect the same way: see the steps. How access and privacy work

Add your phone

  • iPhone: the FTW app, FTW Energy in the App Store. Free, iOS 26 or later. On the box, open Settings → FTW app, choose Show pairing code and scan it with the app. App support
  • Android: an early test build. Ask for it in the FTW Discord.
  • No FTW yet? Try the demo. It shows a simulated home, and so does the app until you pair it.
